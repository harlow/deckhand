# Deckhand site

The marketing site for Deckhand: Astro + Tailwind v4, built to static files and hosted on Netlify
(`netlify.toml` at the repo root points Netlify here).

```sh
npm install
npm run dev       # http://localhost:4321
npm run build     # writes dist/
npm run preview   # serves dist/
```

The waveforms, Camelot wheel and app mockups on the page are drawn in code (`src/components/`) in
the Mac app's colors; the track names in them are made up.
