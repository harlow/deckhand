# Deckhand 0.1.0-beta.2 — unsigned preview

This beta adds Matches for discovering songs in your collection, continuous playlist
playback, and improvements to keyboard browsing and the workspace.

## What's new

- Press **M** on a song to open up to 50 matches, with the seed pinned at the top.
  Browse Smooth, Lift and Change Direction groups, preview with **L**, and press **A**
  to add songs to the playlist you came from. **Esc** returns to your previous list.
- Playback continues through the current track list when a song ends. Explicitly
  queued songs play first, then playback resumes the remaining list.
- **L** previews the highlighted song even when another song is playing.
- **Command-L** reveals and selects the playing song without interrupting playback.
- Playlist and Matches headers share a fading gradient, and the Suggestions pane
  has quieter hover states and aligned dividers.
- Playlist reorder indicators now include a hollow dot aligned with folder depth.
- The app toolbar uses Deckhand's orange record mark.

## Install or update

Download **Deckhand-arm64.dmg**, open it, and drag Deckhand into Applications. Quit
the existing app first and replace it when prompted. Your local library, playlists,
ratings and analysis remain in Application Support.

Requires an **Apple Silicon Mac running macOS 26 or newer**. Homebrew, Python and
developer tools are not required. Audio files stay in their original locations.

This is an **unsigned, unnotarized preview**. Apple Developer ID signing and
notarization are pending, so macOS may block a downloaded copy on first launch.
See [Apple's guidance for opening downloaded apps](https://support.apple.com/en-us/102445).

## Beta limitations

Hardware playback has been confirmed on OMNIS-DUO. Other OneLibrary players need
hardware testing; older players requiring export.pdb are not supported. Protected
Apple Music streaming tracks cannot be exported. There is no automatic updater:
download a newer release to update.

The release includes matching source, license notices and SHA-256 checksums.
