# Deckhand 0.1.0-beta.1

Deckhand brings tracks and playlists from Apple Music, Rekordbox XML or a folder into
one local library, then prepares selected playlists for OneLibrary USB players.

- Playlists, folders and ratings save locally across imports and restarts.
- Analyze key, tempo, waveforms and cues on your Mac; no additional software needed.
- Select playlists, review staged changes and click Sync to update your USB.
- Organize playlists with drag and drop, or browse and rate with keyboard shortcuts.

## Install

Download `Deckhand-arm64.dmg`, open it and drag Deckhand into Applications.
Requires an **Apple Silicon Mac running macOS 26 or newer**. Homebrew, Python and
developer tools are not required. Audio files stay in their original locations.

## Beta limitations

Hardware playback has been confirmed on OMNIS-DUO. Other OneLibrary players need
hardware testing; older players requiring `export.pdb` are not supported.
Use a spare USB for your first test. Protected Apple Music streaming tracks cannot
be exported. This version has no automatic updater: download a newer release to update.

The release includes matching source, license notices and SHA-256 checksums.
